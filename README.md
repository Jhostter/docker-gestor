# 🐳 Docker Gestor

Panel web local para gestionar Docker: contenedores, logs en vivo, terminal, Compose, imágenes, volúmenes, redes, eventos y gráficas de consumo con historial. Muy ligero (≈0,2–0,5 % de CPU en reposo).

```bash
npm install
./scripts/install-service.sh     # compila e instala el servicio systemd de usuario
```

Abre **http://localhost:4455** (solo accesible desde tu equipo).
